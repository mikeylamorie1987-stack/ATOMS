# ATOMS Elementor Custom Styles

This package contains Elementor-specific styles for the ATOMS theme.

## Installation

1. **Extract the ZIP file** to your WordPress theme directory or as a plugin
2. **Activate in WordPress** - Either:
   - Place in `/wp-content/themes/` and activate as a theme
   - Or install Elementor plugin first, then use these styles

## What's Included

- **style.css** - All Elementor widget styles and dark theme customization
- **functions.php** - Elementor location registration and support

## Features

✓ Dark theme color palette
✓ Custom button styles
✓ Form input styling
✓ Card and box hover effects
✓ Typography optimized for Elementor
✓ Responsive design
✓ Theme Builder support
✓ Animation styles

## Color Scheme

- Background: #121212
- Surface: #18181B
- Card: #1F1F23
- Primary Red: #C00000
- Hover Red: #D90429
- Text Primary: #F3F4F6
- Text Secondary: #D1D5DB

## Fonts

- Headings: Oswald
- Body: Inter
- Accent: Cinzel

## Elementor Theme Builder

This package is fully compatible with Elementor's Theme Builder for:
- Custom Headers
- Custom Footers
- Single Post Templates
- Archive Templates
