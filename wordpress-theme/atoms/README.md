# ATOMS - Noble Anarchy Collective Theme

## Overview
ATOMS is a dark, edgy WordPress theme designed for streetwear brands and modern websites. Featuring immersive parallax scrolling, animated typography, and a custom color palette inspired by the Noble Anarchy Collective brand.

## Features
- **Dark Theme**: Custom dark color palette (#121212 background, #C00000 primary red)
- **Elementor Compatible**: Full support for Elementor page builder
- **Responsive Design**: Mobile-first approach with tablet and desktop optimization
- **Custom Typography**: Google Fonts integration (Oswald, Inter, Cinzel)
- **Animation Ready**: JavaScript framework for scroll effects and parallax
- **WooCommerce Ready**: Can be extended for e-commerce functionality

## Color Palette
- **Background**: #121212
- **Surface**: #18181B
- **Card**: #1F1F23
- **Primary Red**: #C00000
- **Hover Red**: #D90429
- **Text Primary**: #F3F4F6
- **Text Secondary**: #D1D5DB

## Installation
1. Upload the `atoms` folder to `/wp-content/themes/`
2. Activate the theme in WordPress admin
3. Go to Appearance > Customize to adjust colors and settings
4. Install Elementor plugin for advanced page building

## File Structure
```
atoms/
├── style.css              # Main stylesheet
├── functions.php          # Theme functions
├── index.php              # Default template
├── header.php             # Header template
├── footer.php             # Footer template
├── page.php               # Page template
├── single.php             # Single post template
├── 404.php                # 404 error page
├── assets/
│   ├── css/
│   │   ├── responsive.css # Mobile responsive styles
│   │   └── admin.css      # Admin panel styles
│   └── js/
│       ├── main.js        # Main theme JavaScript
│       └── customizer.js  # Customizer functionality
├── elementor/
│   ├── header.php         # Elementor header template
│   └── footer.php         # Elementor footer template
├── inc/
│   └── customizer.php     # WordPress customizer settings
└── template-parts/
    └── content.php        # Content template part
```

## Customization
The theme supports WordPress Customizer for:
- Primary color changes
- Background color adjustments
- Font adjustments (via Google Fonts)
- Header/Footer menu configuration
